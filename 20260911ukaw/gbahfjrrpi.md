# 致畸八项是检查什么？有必要检查吗？

> 更新时间：2026-09-11 (UTC+8)

我今年35岁，算是大龄孕妇了，这个孩子是好不容易才怀上的，所以平常就很注意，孕检也很按时，这两天我在网上看到有姐妹在查致畸八项，我的医生还没有让我查这个，我也不知道有这个检查，想问下致畸八项的检查项目是什么？怀孕后还有没有必要做？ 
查看全部内容

孕前致畸八项检查是很有必要的，其检查项目包括有弓形虫IGG抗体、弓形虫IMG抗体、巨细胞病毒IGG抗体、巨细胞病毒IGM抗体、单纯疱疹病毒IGG抗体、单纯疱疹病毒IGM抗体、风疹病毒IGG抗体、风疹病毒IGM抗体，这项检查属于病毒风险监测，如果女性在孕期感染了某一种病毒，都有可能导致孕期流产、早产、死胎、畸形儿等不良妊娠结果，所以需要重视这项检查。

致畸八项的检查时间一般是孕前三个月完成，也可以在孕后两个半月去检查，主要是检查女性病毒感染情况，这些病原体感染后会通过母婴传播影响胎儿，引起不良妊娠结果。下面可以了解一下致畸八项检查的临床意义：

- 1. 孕妇如果感染了弓形虫病毒，可能会导致流产、早产、胎死宫内、婴儿脑积水、神经发育障碍等，一般家养小动物会携带有这项病毒；
- 2. 感染风疹病会引起新生儿畸形、肝脾大、神经发育障碍、先天性心脏病等；
- 3. 感染巨细胞病毒对胎儿的伤害也很大，会导致胎儿宫内死亡，新生儿被感染会出现黄疸、血小板减少性紫癜、溶血性贫血、脑损伤等不良情况；
- 4. 孕妇感染单纯疱疹病毒会造成胎儿先天性感染，诱发流产、早产、死胎等不良妊娠结果，新生儿感染该项病毒死亡率比较高，还常会伴有严重的后遗症。
致畸八项检查是针对病毒感染和寄生虫感染的检查，需要在孕前完场，检查的费用不是很贵，在600-800元左右，因地区、医院不同，这个费用可能会有一定的波动性，此外国家还提供了19项免费的孕检项目，大家也可以多了解一下。
